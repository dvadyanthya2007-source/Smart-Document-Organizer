# Smart Document Organizer (React + Tailwind + Recharts)

1. Unzip this folder (right-click > Extract All). Do NOT run it from inside the zip.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Open the terminal (Ctrl + `) and run:

   npm install
   npm run dev

4. Open the link shown (usually http://localhost:5173)

Requires Node.js 18+ (check with: node -v). Download from https://nodejs.org if missing.
